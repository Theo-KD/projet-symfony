# 🍔 Projet Symfony — Interface de borne de commande

Ce projet a été réalisé dans le cadre d’un exercice consistant à **reproduire l’interface d’une borne de commande** comme celles que l’on peut trouver dans les fast-foods.  
Le thème visuel était libre, permettant une personnalisation complète de l’expérience utilisateur.

---

## 🎨 Thème choisi

J’ai choisi un thème visuel basé sur l’univers des restaurants chinois, avec :

- une palette de couleurs or, blanc et noir
- des motifs rappelant la culture asiatique
- une ambiance chaleureuse et traditionnelle
- une interface moderne mais inspirée des menus digitaux asiatiques
- des visuels adaptés (plats, icônes, typographies)

Ce thème donne une identité forte à la borne et améliore l’immersion utilisateur.

---

## 🧰 Technologies utilisées

- **Symfony 6**
- **PHP 8+**
- **Twig**
- **HTML/CSS/JS**
- **POSTGRESQL**
